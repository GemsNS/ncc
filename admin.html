Site configuration (all public pages)

One JSON document controls the live site when assets/config/runtime.json points at your API. After Save, public pages load it on refresh. Static fallbacks (site-content.json, home-featured-videos.json) are updated automatically for offline preview.

What you can edit (all keys)
  • placeholders — All data-ph page copy and links (home hero, about, ministries, give Sharefaith URL, Cash App, maps, contact).
  • church — Name, address, phone, service times (reference data).
  • socialFeeds — Anthony Inspiration page, Facebook highlights, prayer chat live/offline URLs.
  • live — Ticker items, manual/scheduled status, service timeline, links.youtubeWatch / links.zoom.
  • videoSlots — Every data-ncc-video iframe (livestream main, men’s ministry, legacy archives, Anthony hub). Set embedUrl, overlay: auto | force-online | force-offline.
  • homeFeaturedVideos — Home carousel (videos[] with youtubeId or local src under ./assets/).
  • mediaArchive — Livestream archive grid (title, url, thumbnail, tags, speaker, etc.).
  • sermonNotes — Optional livestream notes list (timestamp, point).
  • calendar.xmlUrl — Optional XML feed merged on the Calendar Events page.
